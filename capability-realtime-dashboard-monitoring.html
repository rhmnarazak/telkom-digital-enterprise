FAQ

Questions about Real-time Dashboard & Monitoring.

What is Real-time Dashboard & Monitoring?

Real-time Dashboard & Monitoring is the shared capability that shows live status on one screen, with history beside it, across the services that use it.

Which services include Real-time Dashboard & Monitoring?

Today it is available in Network Management, Academic Management and IP Camera Management. In Network Management, it covers Network Monitoring, Web/API Monitoring, Linux Server Monitoring, Network Status History, Traffic & Bandwidth Monitoring. In Academic Management, it covers Real-time Institution Monitoring. In IP Camera Management, it covers Device Data Storage & Dashboard.

Do I need a particular service to use it?

Yes. Real-time Dashboard & Monitoring comes with the services that include it, so you use it through Network Management, Academic Management and IP Camera Management. Ask us which package fits your needs.

How does Real-time Dashboard & Monitoring differ between services?

In Network Management, it puts every network device, website, API and server on one dashboard, with history beside it. In Academic Management, it shows the whole institution, from attendance to learning outcomes, as it happens. In IP Camera Management, it stores data from connected devices and shows it on dashboards or in other apps.

How is our data kept secure?

Real-time Dashboard & Monitoring runs inside each service's tenant, with single sign-on and role-based access. Personal data is handled under Indonesia's Personal Data Protection Law (UU PDP No. 27/2022).

How do packages and pricing work?

Pricing follows the service and package you choose. Contact us and we will propose a package for your team.
